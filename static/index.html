What does this measure?

Both texts are converted to vectors, then cosine similarity measures how closely the vectors point in the same direction. A high value suggests related representations, not verified truth.

MATRYOSHKA REPRESENTATIONS

Same model. Different vector sizes.

EmbeddingGemma 2 generates 768 numbers per input. Because the embeddings are Matryoshka-trained, the first 512, 256, or 128 dimensions can be kept and renormalized. This reduces storage and indexing cost, at the expense of some retrieval quality.

Important: query and document vectors must use the same dimensions. Values shown are cosine similarities — not confidence percentages.
